# Edip - Acrobat-Grade Mobile PDF Studio

**Edip** is a native Android application built with **Jetpack Compose** and **Kotlin**, connecting directly to the live cloud PDF engine ([https://edip.run.place](https://edip.run.place)).

---

## Mobile Features

* **Pinch-to-Zoom & Pan:** Smooth multi-touch gesture support to zoom deep into small text, tables, and fine lines.
* **Tap-to-Select Text Objects:** Tap any word, phrase, or line directly on the screen to highlight and open the editor.
* **Mobile Bottom Sheet Editor:**
  * Clean text input with multi-line support.
  * Font Family selector (Helvetica, Times, Courier).
  * Font Size stepper (- / +) to shrink or enlarge text to fit table cells.
  * Color palette for text styling.
  * **Drag to Nudge:** Toggle drag mode to visually move text on screen before applying edits.
* **Page Management:** Previous/Next navigation and instant 90° page rotation.
* **Native Storage & Sharing:** Pick any PDF from phone storage and export/share the clean edited PDF via WhatsApp, Gmail, Drive, etc.

---

## How to Open in Android Studio

1. Open **Android Studio**.
2. Click **File -> Open...** (or click **Open** on the welcome screen).
3. Select the `edip` folder.
4. Click **OK**. Android Studio will automatically sync Gradle and download dependencies.
5. Connect your Android phone via USB (with Developer Mode enabled) or start an Android Emulator.
6. Click the green **Run (▶)** button!
